# Reactive Builder Camp 学习仓库

记录 Reactive Builder Camp 共学期间的环境准备、每日学习笔记与 Reactive Omni 跨链自动化实践。

## 学习目标

跑通「源链事件 → Reactive 合约 react() → 目标链回调」，再逐步构建自己的事件驱动应用。

## 目录

- [notes/](notes/)：每日学习笔记，后续按 `YYYY-MM-DD.md` 命名。
- [第 0 周：环境准备](notes/week-0.md)：已完成事项、待办与验证方法。

当前仓库仅包含学习文档，尚未上传合约代码，也不代表已完成链上部署。

## 安全约定

只使用测试专用钱包与测试网。不要提交私钥、助记词、钱包密钥文件、RPC 密钥或 `.env`。公开笔记只记录必要的合约地址、交易哈希和经过检查的截图。
